# Комиссия.Финансы — Норильск

PWA для финансового и бухгалтерского учёта расходов избирательных комиссий
муниципального образования город Норильск (ТИК города Норильска + 63 УИК).

**Рабочая версия (GitHub Pages):** https://alikerimov65.github.io/komfin-norilsk/

## Возможности

- Реестр комиссий МО город Норильск: автозаполнение карточек (ТИК + 63 УИК,
  постановление Администрации г. Норильска от 21.12.2012 № 442, ред. от 13.04.2026 № 111)
- Смета расходов с контролем лимитов (краевой 40202 / федеральный 40201 контуры)
- Табель → расчётная ведомость вознаграждений (пост. ЦИК 10/101-9, ставки 63/57/45 ₽/ч, ночные/выходные ×2)
- Журнал банковских и кассовых операций, подотчёт и авансовые отчёты УИК
- Отчёт по приложению № 10, экспорт в Excel, печатные формы
- Офлайн-first: все данные — локально в IndexedDB браузера (Dexie)

## Стек

React 19 · TypeScript · Vite 7 · Tailwind · Dexie (IndexedDB) · SheetJS · vite-plugin-pwa
